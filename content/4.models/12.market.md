## 价格与可用性说明

### 为什么比官方 API 便宜这么多？

价格优势主要来自订阅额度池化、账号池调度和缓存命中。我们把原本碎片化、容易闲置的额度做成按量调用服务，让用户不用自己承担整份会员成本。

### 会不会是缩水模型？

不会。我们不做蒸馏替代、不静默换小模型、不把模型名和真实路由拆开。你看到的模型会按对应能力路由，实际可用模型和倍率以控制台显示为准。

### 和自己买 Plus / Pro 有什么区别？

自己买会员会遇到额度窗口、没用完浪费、临时不够用的问题。这里更像即买即用的模型调用额度，适合 Codex、脚本调用、批量任务和 deadline 场景。

### 哪些工具可以接入？

所有支持 OpenAI 兼容接口的工具都可以接入；只需要把本站 Base URL 和 API Key 填到对应工具的 OpenAI API 设置里即可。Codex 已确认可用。
