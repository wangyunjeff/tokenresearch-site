## 准备开始

TokenResearch Docs 用于整理 AI 编程工具的安装、模型、代理、常见配置和可复用 Skill。

建议先准备 Node.js、Git、终端环境和可访问模型服务的网络。

## 第一次怎么读

如果你是第一次进入这个站，建议按这个顺序：

1. 先看 [环境准备](/tutorials/environment)，确认本机能跑项目命令。
2. 再看 [Codex 首次运行](/tutorials/codex-first-run)，确认工作目录和权限。
3. 然后看 [模型评测总览](/models)，建立模型路由方法。
4. 最后看 [Skill Gallery](/gallery)，判断具体任务该调用哪个能力。

## 四个入口

| 入口 | 适合谁 |
| --- | --- |
| [基础教程](/tutorials) | 第一次系统配置 AI 编程工具 |
| [模型评测](/models) | 想判断不同模型和推理等级怎么选 |
| [场景路线](/workflows) | 想把教程、评测和 Skill 串成工作流 |
| [Skill Gallery](/gallery) | 想看每类 Skill 能产出什么结果 |

如果只想看当前复刻页面，直接进入 [Codex配置/使用](/codex/model)。

## 本地运行目标

这个站点优先服务本地修改和复查。开始改内容前，先确认本地服务、路由检查和截图目录都可用；后续部署可以等内容稳定后再做。
