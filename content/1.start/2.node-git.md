## Node.js

这一页只处理系统前置环境：Node.js、pnpm、Git 和终端。模型服务、代理和 AI 工具配置放在 [环境准备](/tutorials/environment) 继续处理。

建议安装当前 LTS 或更高版本，并确认终端可以执行：

```bash
node --version
npm --version
```

这个项目使用 pnpm。安装后确认：

```bash
corepack enable
pnpm --version
```

## Git

安装 Git 后确认：

```bash
git --version
```

## Windows 终端建议

PowerShell 适合运行本地项目脚本和系统命令；Git Bash 适合使用类 Unix 路径和 SSH。不要在同一个任务里混用路径风格，尤其是涉及 `~/.ssh`、环境变量和文件删除时。

## 项目启动检查

进入仓库根目录后，先看这些文件是否存在：

```bash
rg --files -g package.json -g pnpm-lock.yaml -g nuxt.config.ts
```

如果能看到这些文件，再运行：

```bash
pnpm install
pnpm dev
```

启动成功后，继续看 [环境准备](/tutorials/environment)，确认代理、模型服务和项目命令的检查顺序。
