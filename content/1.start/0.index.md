## 先看什么

如果只是第一次打开本站，从这里开始即可。快速开始只做入口导向：先确认本地环境，再进入 Codex 配置和模型测试，最后按任务选择模型、场景路线或 Skill。

## 四个主入口

- [基础教程](/tutorials)：环境、首次运行、Agent 规则和视觉验收。
- [模型中心](/models)：进入模型广场，查看价格、任务路由和评测记录。
- [场景路线](/workflows)：把教程、评测和 Skill 串成可执行工作流。
- [Skill Gallery](/gallery)：展示每个 Skill 的输入、输出、适用场景和结果预览。

## 最小路径

1. 先完成 [安装 Node.js 和 Git](/start/node-git)。
2. 再读 [环境准备](/tutorials/environment)。
3. 如果要改复刻页，直接进入 [Codex配置/使用](/codex/model)。
4. 如果要扩展站点，先看 [视觉复刻路线](/workflows/visual-replica)。
