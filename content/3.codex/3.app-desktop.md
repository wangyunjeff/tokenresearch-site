## 适合做什么

桌面端适合管理本地线程、查看文件改动、运行终端命令和执行可视化检查。

它的价值在于把聊天、文件、终端和视觉输出放在同一个上下文里。做网站、文档、PPT、PDF 或截图验收时，比纯终端更容易发现布局和内容问题。

## 推荐工作流

| 阶段 | 动作 |
| --- | --- |
| 开始前 | 确认当前 workspace 是真实项目目录 |
| 处理中 | 让 Codex 读取相关文件、修改、运行检查 |
| 视觉检查 | 打开本地页面或渲染文件，截图比对 |
| 结束前 | 汇总改了哪些文件、哪些检查通过 |

## 线程管理

同一个项目的连续任务尽量留在同一线程，避免重复解释背景。完全不相关的任务再新开线程。

如果一个任务已经进入长程目标模式，后续指令要明确是继续当前目标、缩小范围，还是暂停。

## 交付标准

桌面端任务不要只停在“代码看起来对”。能运行就运行，能截图就截图，能构建就构建。最后至少给出本地 URL、关键文件路径和检查结果。
