## 模型切换

使用 `/model` 命令可以切换模型。

::warning
推理等级选择 high(高)：适合大多数场景，兼顾速度和质量。xhigh(超高)：适合更复杂的思考场景，速度较慢，不适合简单任务。
::

## 手动配置模型

最新的模型可能不在 Codex 模型默认列表中。

修改配置文件： `~/.codex/config.toml`

```toml
model = "gpt-5.5"
```

## 远程压缩

如果经常遇到上下文被压缩导致的错误，或者上下文丢失，可以在配置文件中调整远程压缩行为。

修改配置文件： `~/.codex/config.toml`

关闭远程压缩：把 `name = "OpenAI"` 改成 `name = "ylscode"`，可以关闭自动远程压缩。

启用远程压缩：把 `name = "ylscode"` 改成 `name = "OpenAI"`，可以启用自动远程压缩。

## 1M上下文配置

::warning
当上下文超过 270K Token 时，使用阶梯计价通常会变为正常价格的两倍，详情以官方 API 计价文档为准。
::

开启 1M 上下文后会导致模型注意力明显下降，结果可能变差。除非有特殊需求，否则不建议修改上下文配置。

打开 `config.toml` 配置文件，删除以下配置，保持上下文配置默认即可：

```toml
model_context_window
model_auto_compact_token_limit
```

## Agents / Multiple agents

Codex `0.115.0` 及以上版本默认开启多 Agent 功能，触发时会消耗更多 Token。

不要随意调整默认 Agent 数量。更多 Agent 不一定带来更好的结果，反而可能产生冲突，导致输出质量下降。

更多使用方式可以查看 [官方文档多 Agent](https://developers.openai.com/codex/subagents)。

## goal 命令(目标模式)

Goal 模式是 Codex CLI 在 `v0.128.0` 版本中加入的实验性特性，它提供一种新的交互范式，可以为 Codex 设定持久目标。

#### 开启方式

修改配置文件： `~/.codex/config.toml`

```toml
[features]
goals = true
```
