## 插件定位

IDE 插件适合解释当前文件、生成局部补丁、查看诊断信息和从编辑器内发起短任务。复杂任务仍建议回到 CLI 或桌面端，因为它们更容易完整运行测试和检查文件树。

## 安装后核对

安装 IDE 插件后，确认插件读取的账号、模型和网络配置与本机 CLI 保持一致。

| 项目 | 检查方式 |
| --- | --- |
| 项目根目录 | 插件侧边栏显示的 workspace 是否是仓库根目录 |
| 模型 | 插件模型名是否与 CLI 配置一致 |
| 网络 | IDE 代理设置是否继承系统代理或终端代理 |
| 权限 | 插件是否能读取当前打开的文件和诊断 |

## 使用边界

适合：改一个函数、解释报错、生成测试样例、补全文档。

不适合：跨多个包的大重构、需要长时间运行服务的前端验收、需要频繁切换终端环境的服务器排查。

## 排错顺序

1. 先在终端确认 CLI 可以运行。
2. 再检查 IDE 插件是否登录同一个账号。
3. 最后对比模型名、代理地址和工作目录。
