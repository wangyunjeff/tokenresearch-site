## 章节定位

Claude Code 页面用于记录 CLI、插件和模型预算相关配置。它和 Codex 页面并列，便于同一个项目在不同 AI 编程工具之间保持工作目录、权限和模型策略一致。

## 推荐阅读顺序

1. [安装 Claude CLI](/claude-code/install-cli)：确认账号、权限和项目目录。
2. [插件配置](/claude-code/plugin)：让插件和 CLI 使用一致的上下文。
3. [模型配置](/claude-code/model)：按任务复杂度选择模型和推理预算。
