## 插件

插件配置应与 CLI 的模型、权限和工作目录保持一致。

## 检查项

| 检查项 | 说明 |
| --- | --- |
| 登录状态 | 插件账号是否与 CLI 一致 |
| 项目目录 | 当前 IDE workspace 是否为仓库根目录 |
| 文件权限 | 插件是否能读取相关目录 |
| 终端权限 | 是否允许运行项目脚本 |
| MCP | 是否启用了不必要的外部工具 |

## 使用建议

插件更适合就地解释和小范围修改。需要创建新文件、运行长命令、截图或检查构建产物时，CLI/桌面端更容易完整验收。

## 插件适合做什么

| 任务 | 建议 |
| --- | --- |
| 解释当前文件 | 适合插件 |
| 小范围重命名或补注释 | 适合插件，但要看 diff |
| 跨目录新增页面 | 更适合 CLI 或 Codex 桌面端 |
| 跑构建和浏览器截图 | 更适合 CLI、Codex 或 Browser Visual QA |

## 风险边界

IDE 插件看到的上下文通常由当前 workspace 和打开文件决定。做模型评测时，要把插件、CLI 和桌面端分开记录，不要把同一个模型在不同工具表面的表现混为一谈。
