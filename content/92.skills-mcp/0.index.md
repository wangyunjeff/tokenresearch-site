## 章节定位

Skills 适合沉淀稳定流程，MCP 适合让 Agent 访问实时工具或外部系统。这个章节负责说明什么时候写 Skill、什么时候接 MCP、什么时候只需要普通文档页。

## 推荐阅读顺序

1. [Skills 推荐](/skills-mcp/skills)：哪些流程应该写成可复用 Skill。
2. [MCP 使用边界](/skills-mcp/mcp-overview)：MCP 适合做实时查询和工具访问，不适合替代项目规则。
3. [chrome-devtools-mcp](/skills-mcp/chrome-devtools-mcp)：用于浏览器调试、DOM 检查和视觉验收。

## 和 Gallery 的关系

Skill 页面写“怎么做”，Gallery 页面展示“做出来是什么样”。如果一个 Skill 已经有稳定产出，应在 [Skill Gallery](/gallery) 中补展示卡片和详情页。
