## 这部分解决什么问题

基础教程不是单个工具的命令速查，而是把使用 AI 编程工具的顺序梳理清楚：先准备环境，再理解配置文件和模型，再学会让 Agent 做可验证的工作。

::tip
如果你只想修改已经复刻的 Codex 模型页，直接看 [Codex配置/使用](/codex/model)。
::

## 学习路径

1. 环境准备：Node.js、Git、终端和代理。
2. Codex 首次运行：确认模型、权限、工作目录。
3. Agent 规则：把项目约束写进 `AGENTS.md`。
4. 视觉验收：用真实浏览器截图检查网页。
5. 质量门禁：用 lint、typecheck、route check 和 build 固化最低验收。
6. 产出沉淀：把可复用流程做成 Skill 或 Gallery 页面。

## 输出标准

完成这组教程后，应该能做到：

- 本地跑起 Nuxt UI Docs 站点。
- 找到全局和项目级配置文件。
- 判断什么时候用普通模型、什么时候用高推理模型。
- 让 Codex 在修改后运行 lint、typecheck、build 和浏览器检查。
