## 必备环境

如果 Node.js、pnpm 或 Git 还没安装，先回到 [安装 Node.js 和 Git](/start/node-git)。这一页默认系统命令已经存在，重点检查 AI 编程工具运行时会依赖的网络、代理和项目命令。

```bash
node --version
npm --version
pnpm --version
git --version
```

本项目使用 Nuxt 4、Nuxt UI、Nuxt Content 和 pnpm。开发时优先确认本地命令可用，再处理模型和代理问题。

## 网络和代理

如果外网访问不稳定，先区分三类代理：

| 位置 | 常见影响 | 检查点 |
| --- | --- | --- |
| 系统代理 | 浏览器、部分 GUI 工具 | 是否能打开文档和模型服务 |
| 终端环境变量 | npm、pnpm、CLI | `HTTP_PROXY` / `HTTPS_PROXY` |
| 工具配置 | Codex、OpenCode、Claude Code | 工具自己的 config 文件 |

## 项目命令

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm build
```

开发站点时保持 `pnpm dev` 运行，再用浏览器或 Playwright 做视觉检查。

下一步进入 [Codex 首次运行](/tutorials/codex-first-run)，确认模型、权限和工作目录。
