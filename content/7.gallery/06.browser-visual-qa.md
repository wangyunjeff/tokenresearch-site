## 场景

前端页面、文档站、仪表盘、交互工具和移动端布局都应该做真实浏览器检查。

:skill-result-showcase

## 输入

- 本地或线上 URL。
- 需要检查的视口尺寸。
- 参考截图或设计目标。

## 示例输入

```text
请检查 /gallery 和 /codex/model 在 1440px 桌面、390px 移动端和 dark mode 下是否有溢出、遮挡、404 或亮色漏底。
保存截图并列出需要修复的组件。
```

## 产出

- 桌面端和移动端截图。
- 布局问题列表。
- 修复后的二次截图。

## 推荐截图组

| 截图 | 目的 |
| --- | --- |
| `desktop.png` | 左导航、正文、右 TOC 同屏检查 |
| `mobile.png` | Header、菜单、标题、按钮和代码块 |
| `dark.png` | 暗色背景、边框、图标和卡片对比度 |
| `after-fix.png` | 修复后确认同一问题不再出现 |

## 当前站点示例

本项目已经保存了 `/codex/model` 的参考截图和本地截图，位置在 `output/playwright/`。

## 检查重点

- Header 是否在移动端溢出。
- 长标题和按钮文字是否重叠。
- 暗色模式是否有亮色漏底。
- 卡片、表格和代码块是否在窄屏横向挤压。
