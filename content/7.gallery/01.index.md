## 展览区定位

Skill Gallery 是给使用者快速判断能力边界的页面：这个 Skill 能做什么，结果长什么样，什么场景值得调用，什么时候不要调用。

:skill-gallery-preview

## 展示方法

这里借鉴示例图库的组织方式：先按场景分组，再用卡片展示输入、输出和结果预览。每个详情页继续往下说明适用边界，避免只看到漂亮缩略图却不知道什么时候该用。

## Gallery 卡片标准

每个 Skill 页面都固定回答四个问题：

| 问题 | 说明 |
| --- | --- |
| 场景 | 用户为什么会需要它 |
| 输入 | 需要文件、URL、数据还是自然语言 |
| 产出 | 会生成文档、图表、截图、PPT、报告还是代码 |
| 边界 | 什么情况下不适合用 |

## 推荐入口

- [Paper Analyze](/gallery/paper-analyze)：读论文和提炼图文笔记。
- [Presentation Builder](/gallery/presentation)：生成和检查 PPTX。
- [Spreadsheet Analyst](/gallery/spreadsheet)：分析 CSV/XLSX 实验结果和统计图表。
- [Browser Visual QA](/gallery/browser-visual-qa)：前端视觉验收。
- [Zotero Research](/gallery/zotero-research)：整理本地文献库和阅读线索。
- [Research Loop](/gallery/research-loop)：研究选题和迭代。
- [PDF and Docs](/gallery/pdf-docs)：生成、填写和渲染检查文档。
- [Ops Debug](/gallery/ops-debug)：服务器、端口和代理现场排查。
- [LaTeX Paper](/gallery/latex-paper)：编译和检查论文源码。
- [Diagram Canvas](/gallery/diagram-canvas)：生成可编辑系统图和流程图。
- [Hatch Pet](/gallery/hatch-pet)：生成动画宠物资源包并做视觉 QA。

## 组合使用

| 任务 | 推荐组合 |
| --- | --- |
| 写论文和准备组会 | Paper Analyze、LaTeX Paper、Presentation Builder |
| 做实验结果报告 | Spreadsheet Analyst、Diagram Canvas、PDF and Docs |
| 复刻或改版网站 | Image Generation、Browser Visual QA、Ops Debug |
| 找研究方向 | Zotero Research、Research Loop、Paper Analyze |
