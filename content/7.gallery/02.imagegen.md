## 场景

当页面需要真实的视觉资产、封面、缩略图、图标风格探索或素材变体时使用。

:skill-result-showcase

## 输入

- 目标页面或展示位置。
- 风格约束。
- 尺寸和背景要求。
- 是否需要透明背景。

## 示例输入

```text
为 Skill Gallery 首页生成一张 16:9 缩略图。
风格要像现代开发者工具，主体是文档、截图和可交付文件，不要包含可读文字，背景可用于浅色模式。
```

## 产出

| 类型 | 示例 |
| --- | --- |
| 网站视觉 | Hero 背景、Gallery 缩略图 |
| 教程素材 | 操作示意图、封面图 |
| 产品图 | 图标、卡片插图、场景图 |

## 验收清单

- 主体在目标裁切比例里清楚，不靠纯氛围图撑页面。
- 没有生成难以修复的乱码文字、错位 UI 或伪按钮。
- 透明素材边缘干净，放到深色和浅色背景上都可读。
- 文件尺寸、命名和用途能被后续页面复用。

## 不适合

不要用它生成需要精确文字、精确 UI 截图或可直接编辑的矢量图。那类任务应该用代码、SVG 或截图工具。

## 典型流程

1. 确认用途、尺寸、背景和风格边界。
2. 生成一版主图或透明素材。
3. 放回页面或文档里检查真实效果。
4. 根据截图调整裁切、对比度和主体位置。
