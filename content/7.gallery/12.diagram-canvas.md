## 场景

需要把系统结构、研究路线、方法模块、数据流或工具调用流程可视化时使用。

:skill-result-showcase

## 输入

- 节点、边、层级和分组关系。
- 目标格式：Excalidraw、JSON Canvas、Mermaid、SVG 或 PPT 图。
- 是否需要适配论文、README、网站或演示稿。

## 示例输入

```text
把这个 AI coding workflow 画成可编辑图：用户目标 -> 读 AGENTS -> 修改 content -> 跑质量门禁 -> 浏览器截图 -> 记录结果。
输出 Mermaid 和可放进文档的 SVG。
```

## 产出

- 可编辑图示文件。
- 适合展示的 SVG/PNG。
- 图中节点、箭头、分组和说明文本。

## 交付格式选择

| 格式 | 适用 |
| --- | --- |
| Mermaid | 文档内维护、版本控制和快速修改 |
| Excalidraw | 手绘风格、协作标注和演示 |
| JSON Canvas | Obsidian 知识图谱和节点式整理 |
| SVG/PNG | README、PPT 和网站静态展示 |

## 使用边界

如果只是临时解释一个很小的流程，Markdown 列表即可。需要反复修改、嵌入文档或给别人协作时，再生成正式图示。

## 验收标准

图示必须能表达主路径、关键分支和模块边界，文本不能堆叠，移动到文档或 PPT 后仍然可读。
