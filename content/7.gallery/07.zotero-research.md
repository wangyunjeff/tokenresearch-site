## 场景

需要从本地文献库找论文、整理 collection、写笔记或核对元数据时使用。

:skill-result-showcase

## 输入

- 查询关键词。
- Zotero collection 或标签。
- 需要输出的笔记格式。

## 示例输入

```text
在我的 Zotero 文献库里找和 diffusion policy、robot manipulation、sim2real 相关的论文。
优先读取全文附件，按“必读 / 相关 / 只做背景”分组，并生成一份 Obsidian 笔记。
```

## 产出

- 论文列表和摘要。
- Zotero note。
- 标签、collection 或元数据修正建议。

## 示例产出

| 交付件 | 说明 |
| --- | --- |
| 阅读清单 | 标题、作者、年份、venue、collection、附件是否可读 |
| 主题聚类 | 方法、benchmark、应用场景和可复现实验线索 |
| Zotero 整理建议 | 需要补 DOI、移动 collection、增加标签的条目 |
| 笔记 | 可放进 Obsidian 或 Zotero note 的结构化摘要 |

## 验收清单

- 明确哪些结论来自全文，哪些只来自题名、摘要或元数据。
- 每条推荐都能回到 Zotero 条目或附件。
- 不把本地库没有覆盖的方向误说成“没有相关工作”。
- 需要查新时，把 Zotero 结果和在线搜索分开标注。

## 不适合

如果只是查最新论文而本地库没有覆盖，应该走在线文献搜索或 novelty-check。

## 输出标准

结果要说明来自哪个 collection、哪些条目最相关、是否读到了全文附件，以及哪些结论只是标题/摘要层面的判断。
