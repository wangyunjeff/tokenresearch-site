## 场景

读单篇论文、快速判断贡献、整理方法流程、提取图表和形成可复用笔记。

:skill-result-showcase

## 输入

- PDF、arXiv 链接或本地论文文件。
- 关注点：方法、实验、创新性、局限、复现难度。

## 示例输入

```text
请分析这篇论文，重点看它解决的问题、方法结构、实验是否支撑 claim、最接近的相关工作，以及复现风险。
如果能从源码包提取图，请把关键图和表整理到笔记里。
```

## 产出

- 论文摘要和贡献拆解。
- 方法流程图或结构化解释。
- 图表提取和说明。
- 可信度、复现难度和相关工作线索。

## 可交付结构

| 模块 | 内容 |
| --- | --- |
| 问题定义 | 论文要解决的问题和不解决的问题 |
| 方法拆解 | 模块、输入输出、训练或推理流程 |
| 实验证据 | 主表、消融、指标和 baseline 是否充分 |
| 风险判断 | 复现难点、缺失细节、可能被审稿人质疑处 |

## 示例结果

```md
核心问题：模型在长序列上的记忆退化。
方法：增加检索模块和分段训练。
证据：主表显示长上下文任务提升明显，但消融不足。
风险：数据集规模和真实部署延迟没有交代。
```

## 使用边界

如果任务只是翻译摘要，不需要启动完整论文分析流程。完整流程适合要判断方法价值、整理 related work 或准备复现实验时使用。
