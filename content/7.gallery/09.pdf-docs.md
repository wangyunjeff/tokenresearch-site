## 场景

合同、论文、申请表、报告和需要版式保真的文档。

:skill-result-showcase

## 输入

- PDF、DOCX 或需要生成的内容。
- 格式要求。
- 是否需要渲染检查。

## 示例输入

```text
请把这个 DOCX 表单填好并保持原版式不变。
完成后渲染成页面截图，检查表格边框、分页和签名区域是否错位。
```

## 产出

- 可交付 PDF 或 DOCX。
- 页面截图。
- 文本抽取、表格抽取或批注。

## 示例产出

| 文件 | 用途 |
| --- | --- |
| `filled-form.docx` | 保留原格式的可编辑文件 |
| `filled-form.pdf` | 便于发送和归档的最终版本 |
| `rendered/page-*.png` | 逐页视觉验收截图 |
| `qa-notes.md` | 字段、分页、表格和字体检查记录 |

## 验收清单

- 文档页数、分页位置和表格边框符合原要求。
- 填写字段没有溢出、压线或覆盖原文字。
- PDF/DOCX 双版本内容一致。
- 版式敏感任务必须看渲染图，不能只看源文本。

## 使用边界

文档任务不能只看源文件。版式相关任务必须渲染后检查。

## 检查重点

文档任务结束前要尽量渲染页面图，检查分页、表格边框、字体、图像位置和批注是否符合预期。
