# 实验记录

让配置、运行和结果始终对得上。

## 使用范围
围绕用户当前研究任务工作，沿用用户已确定的研究目标、材料范围、实验结果和表达要求。先利用已有材料推进；缺少会影响判断的关键材料时再指出具体缺项。

## 需要的材料
- 配置文件与运行日志
- 代码版本信息
- 结果文件

## 工作顺序
1. 以运行标识关联代码版本、配置、数据划分、随机种子与输出路径。
2. 从日志提取指标与运行状态，保留指标定义及单位。
3. 比较运行间真正发生变化的设置，并标出中断或缺失记录。
4. 生成可供下一次实验延续的记录表与待办。

## 任务中的判断准则
从实际日志读取结果，保留原始文件。每条记录包括运行标识、代码版本、配置、数据划分、种子、指标定义和产物路径；缺失字段如实留空。中断运行与完整运行分别标记。

## 交付
- 实验索引表
- 配置差异摘要
- 未完成与待复查项目

交付内容应能让研究者接着修改或开展下一步。用清楚的文件名与材料位置说明来路，按本次请求决定输出格式。

## 任务示例
请用实验记录 Skill 整理这个目录中的配置、日志和结果。建立对应关系，找出未记录或互相不一致的设置，并输出一份可继续维护的实验索引。
